# proyecto-ikea

Cómo hacer una sesión de prueba

1. Abre la app. En el código de sesión escribe DEMO-C (construcción) o DEMO-O (observación) y sigue el flujo hasta el final.
2. Para sesiones reales, el código lo asignas tú: C01, C02… (construcción) y O01, O02… (observación). El grupo sale del código, no de lo que elija el participante. Un código real ya usado se rechaza.
3. El panel de investigadores está en la misma URL agregando #investigadores al final (PIN: taller2026). Ahí puedes lanzar demos, ver los 6 diseños, revisar registros, exportar CSV, borrar datos demo y reiniciar la sesión. El PIN está dentro del código, así que es una barrera visual y no seguridad real. Cámbialo en la constante PIN.
